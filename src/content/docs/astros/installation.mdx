## Requirements

- **x86-64** machine with **UEFI** firmware
- A **TPM 2.0** module
- 30GB disk space (both `/usr` partitions need at least 5GB)
- 8GB USB stick for installation

## Download

Grab the latest image:

[AstrOS-installer_latest_x86-64.raw.zst](https://dl.astros-linux.org/AstrOS-installer_latest_x86-64.raw.zst)

[SHA256SUMS](https://dl.astros-linux.org/SHA256SUMS)

Write it to a USB stick. We recommend [caligula](https://github.com/ifd3f/caligula):

```sh
caligula burn AstrOS-installer_latest_x86-64.raw.zst
```

Any tool that writes a raw image (e.g. `dd`) works too. Remember to decompress the image.

## Install

<Steps>

1. Ensure that Secure Boot is in Setup Mode.
2. Boot the usb stick.
3. Select and confirm your disk to install to.
4. Done

</Steps>

### Secure Boot

<Aside type="caution">Depending on your hardware, enrolling Secure Boot keys can soft-brick your machine. Learn more on our dedicated [Secure Boot page](/astros/secure-boot).</Aside>

To enable Secure Boot, select the `Enroll Secure Boot Keys` option before booting the system for the first time.
If you do this after booting for the first time, it will break PCR7, which will
require you to [re-enroll the TPM2](/astros/troubleshooting/#how-to-re-enroll-the-tpm).

### First Boot Setup

It is very important to save the recovery key. Your data will be lost if you don't save it and the tpm fails to unlock your root partition!
