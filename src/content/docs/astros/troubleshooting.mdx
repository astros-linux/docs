## How to re-enroll the tpm?

<Aside type="caution">You will need your recovery key</Aside>

First wipe any old stale tpm's:

```sh
sudo systemd-cryptenroll --wipe-slot tpm2 /dev/disk/by-label/luks-AstrOS-root
```

Enroll your tpm2, you will be asked for your recovery key.

```sh
sudo systemd-cryptenroll --tpm2-device auto --tpm2-pcrs=7 /dev/disk/by-label/luks-AstrOS-root
```

## How to rollback?

1. Reboot.
2. When the systemd-boot menu appears, select the other image entry. If the menu
   does not appear on its own, hold <kbd>Space</kbd> during boot to force it.
3. Press <kbd>Enter</kbd> to boot the selected entry.

To confirm which build you landed on:

```sh
cat /etc/os-release
```

## Why doesn't my recovery key work?

You probably have a keyboard from outside the US where the `-` is in a different
position or the `y` and `z` are switched. Try replicating the US keyboard layout.

## Updatectl update fails

Check if the _esp_ is mounted under /boot

If it isn't, mount it manually using:

```sh
sudo mount /dev/disk/by-partlabel/esp /boot
```

If this issue persists, please reach out to Support.

## libvirtd fails to start

Try to delete the following file and restart libvirtd.

```sh
sudo rm /var/lib/libvirt/secrets/secrets-encryption-key

sudo systemctl restart libvirtd
```
